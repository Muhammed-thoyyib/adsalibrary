# **App Name**: Catalogify

## Core Features:

- Secure User Authentication & Authorization: Implement robust user login for both Librarians (Admin) and Members, ensuring role-based access controls to different sections and features of the application.
- Book Catalog Management: Librarians can easily add new books, update existing book details (title, author, ISBN, category, total copies, location), and remove books from the library catalog via an intuitive interface.
- Member & User Account Management: Librarians can manage library members, including adding new members with details like name, email, member ID, phone, and role, and updating their status.
- Book Lending & Return System: Librarians can efficiently track the issuance of books to members and mark books as returned, automatically updating inventory and transaction records.
- Searchable Public Catalog (OPAC): Members can search the entire library catalog by title, author, or category and view detailed information for each book, including its current availability status.
- Personal Borrowing Dashboard: Members can access a personalized section to view all books they have currently borrowed, along with their respective issue and due dates.
- AI Book Insight Tool: An AI-powered tool for Librarians to generate concise, engaging summaries or highlight key themes for new books based on provided details, enhancing catalog enrichment and discoverability for members.

## Style Guidelines:

- Primary color: A deep, professional blue (#243F93) that symbolizes knowledge and reliability, providing a strong anchor for interactive elements and key headings on a light background.
- Background color: A very subtle, cool-toned off-white (#F2F4F7) derived from the primary hue, ensuring a clean, calm, and readable canvas for all content.
- Accent color: A vibrant cyan-blue (#1AC8EB) will be used for calls to action, interactive highlights, and status indicators, offering a refreshing contrast and drawing user attention where needed.
- Headlines: 'Space Grotesk' (sans-serif) for its modern, slightly technical yet clean and impactful presence, suitable for drawing attention to main sections.
- Body Text: 'Inter' (sans-serif) for its excellent readability and neutral, professional aesthetic, ensuring clarity for book descriptions, lists, and form fields across various screen sizes.
- Utilize clean, minimalistic line-art or filled vector icons. Focus on clarity and common library-related metaphors (books, users, search, transactions) for easy visual comprehension and consistent branding.
- Employ a responsive and adaptive layout, ensuring optimal viewing and functionality across desktop and mobile devices. Prioritize intuitive navigation, data visibility for administrators, and streamlined search experiences for members.
- Incorporate subtle and swift micro-animations for user feedback, such as hover effects on buttons, smooth transitions for page loading, and confirmation indicators, enhancing the perceived responsiveness without distracting the user.
